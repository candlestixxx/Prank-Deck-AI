# Deployment & Local Setup

## Requirements
- Node.js (v18+)
- npm

## Setup
1. Clone the repository locally.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```

## Build
To build for production (local static hosting):
```bash
npm run build
```
The output will be placed in the `dist` directory. Do not clear this directory manually during deployment phases.
