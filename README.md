# PrankDeck Studio (Local Edition)

A safe, web-based soundboard and voice effects application designed strictly for personal entertainment and local audio playback. This version does *not* include any system-level audio injection, OS driver manipulation, or third-party app spoofing capabilities.

## Features

- **Mega Soundboard:** A responsive UI grid containing locally synthesized sound effects.
- **Voice Studio:** A local audio recording tool that applies basic DSP pitch-shifting effects (Chipmunk, Monster) directly in the browser using the Web Audio API.

## Setup

```bash
npm install
npm run dev
```
